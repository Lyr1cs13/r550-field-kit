# 双车巡航

两台车可保留 `192.168.0.100`。每块外接无线网卡关联一台车的热点，二号车热点使用 `_B` 后缀。Windows 将二号车的控制端口通过 SSH 转发至虚拟机，VM 的双车面板按两个地址分别连接。车端 ROS 域也分别配置。

双击虚拟机桌面的「巡航演示」，打开「巡航管理」。只有一台车在线时，页面自动选中该车。两台在线时，用「一号车」「二号车」切换各自的任务。共用地图显示两车位置和各自的充电桩。

单车模式下，另一台车停稳或关机后，当前车可照常巡航、采集和回充。两车停稳时可启用「双车联动」，再分别下发各自区域内的点位。完成联动后，让两车停稳，切回「单车模式」，选一号车继续原来的测试。

## 切换车端版本

两个工程各有源码、地图、日志和运行目录。二号车旧工程在 `~/r550_field_kit`，新工程在 `~/lab_cruise_dual`。先在正在使用的工程中执行 `./kit stop`，再在目标工程中执行 `./kit nav`。底盘串口和雷达一次交给一个版本。

## 双车并行

在同一张图上确认两车的起点和独立运行区，再填写 `state/fleet_zone.json`。`bounds` 顺序为 `[xmin, xmax, ymin, ymax]`，单位为米。两区边界至少相隔 0.25 m，示例测试路线还须留出足迹、制动和定位余量。

各车独立检查实时定位、雷达与地图匹配及当前路线。定位过期、接近本车边界、路径越界或面板许可超时，车端撤销速度许可。回充时在同一页面切回单车模式，再对相应车辆点「主动回充」。

标定独立桩位时，按真实充电停靠姿态执行 `./kit scene dock 场景名 --pose X Y DEG`。两车的 `map_id` 相同，各自保存桩位与任务数据。

同一路线上双车配合采样时，使用 [FAS 双车联调](13-fas-dual-radio.md)的走廊预约和回充续作流程。
