# 双车巡航

两台车可保留 `192.168.0.100`。每块外接无线网卡关联一台车的热点，二号车热点使用 `_B` 后缀。Windows 将二号车的控制端口通过 SSH 转发至虚拟机，VM 的双车面板按两个地址分别连接。车端 ROS 域也分别配置。

双击虚拟机桌面的「巡航演示」，打开「巡航管理」。只有一台车在线时，页面自动选中该车。两台在线时，用「一号车」「二号车」切换各自的任务。共用地图显示两车位置和各自的充电桩。

星闪用 2.4 GHz。两车控制热点使用 5 GHz，一号车用信道 48（5.240 GHz），二号车用信道 44（5.220 GHz），带宽均为 20 MHz。C5 采集包 `FAS_Dual_C5_Offline_20261118.zip` 的基站主控和两车共用的客户端固件均设置为信道 36（5.180 GHz）、20 MHz。更换 C5 固件时可从启动日志核对信道。

新车可在有线连接下按厂家的 Soft AP 步骤配置 `/etc/hostapd.conf`，设置 `hw_mode=a` 和对应的 `channel`，使用 20 MHz。用车端 `iw dev wlan0 info` 和 Windows `netsh wlan show interfaces` 核对两端信道。[RDK X5 热点配置](https://d-robotics.github.io/rdk_doc/en/System_configuration/network_blueteeth/)

状态回包超时后，页面显示「正在重连」，保留当前选车和点位。收到新状态后自动恢复控制。连续 6 秒没有有效状态才显示「离线」。等待期间仍可尝试停车。

连接出现串车或离线时，在 Windows 用 PowerShell 7 运行 `tools/fleet_relay.ps1`。它按各自的热点和 SSH 主机密钥建立独立转发，断线后分别重连。虚拟机的 `state/fleet/panel.json` 中，一号车地址填 `http://127.0.0.1:18890`，二号车填 `http://127.0.0.1:18892`。一号车的新场地页面地址填 `http://127.0.0.1:18896`。

在 `panel.json` 添加 `"position_pairs": {"route": "north-u-50.json", "window_s": 2}`，并把对应地图的 50 点路线放在同一目录。两车启用 [仅验证双车通行](13-fas-dual-radio.md#仅验证双车通行) 后，在巡航管理点「开始 50 点无采集测试」启动。地图的「50 个采集点」可以切换编号、朝向箭头和目标点。点「停止 50 点测试」让两车停车，进度保存在该目录的 `position-pairs.sqlite`，下次启动接着跑。

模拟采集持续调度位置对，直至按下暂停或停车。临时掉线、路线受阻或定位待复核期间，面板显示等待原因并保留当前轮次。恢复可通行后重新预约，低电量进入回充队列，充电和桩位校准通过后从同一轮继续。明确停车只接受手动续跑。

北区使用统一朝左的 50 点路线。面板以地图 +X 向上、+Y 向左，建点时传入 `--heading-deg 90`。沿横走廊向左前进、向右倒车，沿右侧竖走廊先对准直线，到点再转回朝左。更换采集朝向时在 `position_pairs` 指定新路线和新的 `journal` 文件名，旧朝向的轮次可单独复现。

单车模式下，另一台车停稳或关机后，当前车可照常巡航、采集和回充。两车停稳时可启用「启用分区联动」，再分别下发各自区域内的点位。完成联动后，让两车停稳，切回「单车模式」，选一号车继续原来的测试。

## 切换车端版本

两个工程各有源码、地图、日志和运行目录。二号车旧工程在 `~/r550_field_kit`，新工程在 `~/lab_cruise_dual`。先在正在使用的工程中执行 `./kit stop`，再在目标工程中执行 `./kit nav`。底盘串口和雷达一次交给一个版本。

## 双车并行

在同一张图上确认两车的起点和独立运行区，再填写 `state/fleet_zone.json`。`bounds` 顺序为 `[xmin, xmax, ymin, ymax]`，单位为米。两区边界至少相隔 0.25 m，示例测试路线还须留出足迹、制动和定位余量。

各车独立检查实时定位、雷达与地图匹配及当前路线。定位过期、接近本车边界、路径越界或面板许可超时，车端撤销速度许可。回充时在同一页面切回单车模式，再对相应车辆点「主动回充」。

标定独立桩位时，按真实充电停靠姿态执行 `./kit scene dock 场景名 --pose X Y DEG`。两车的 `map_id` 相同，各自保存桩位与任务数据。

同一路线上双车配合采样时，使用 [FAS 双车联调](13-fas-dual-radio.md)的走廊预约和回充续作流程。

## 二号车回充排查

- 点「主动回充」后，先看二号车运行记录的时间。若没有新的回充事件，核对面板所选车辆、热点、转发端口和实际运行的工程目录。两台车可以使用相同 IP，网卡和 SSH 主机密钥必须对应各自车辆。
- 若记录已出现「开始主动回充」，核对当前地图、二号车自己的桩位和桩前朝向。克隆工程后，在现场激活场景并标定本车充电桩。两车共用地图，但各自保存桩位。
- 若已到桩边，按时间顺序查看红外、轮停、充电电流和最终事件。红外持续丢失时检查桩前朝向、遮挡与相邻桩信号。触点贴合后检查桩电源、接触条和持续充电反馈。有时轮程保护先停车，数秒后才确认稳定充电。
- 分区联动下，先停稳两车，再切回单车模式执行主动回充。50 点无采集测试有独立的「低电回充」开关和「结束测试并回充」按钮。
