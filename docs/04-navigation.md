# 导航、校准与回充

## 场景配置

每个场地分别保存地图、桩位、禁区和采集路线。切场景时先关闭运行程序：

```bash
./kit stop
./kit scene use room1
./kit nav
```

打开 `http://小车IP:8890/`。启动器只启动服务，不自动发车。

## 第一次标桩

车尾贴紧充电条、车头朝场内，用 RViz 设置实际位置与朝向，核对红点墙线，读取地图坐标 `x y yaw`。将 yaw 转成度后：

```bash
./kit stop
./kit scene dock room1 --pose X Y DEG
./kit scene use room1
./kit nav
```

默认离桩 0.30 m，桩前点沿车头方向前移 0.60 m；原生接管角偏移 -15°。桩前空间不同可用 `--distance`、`--angle` 调整并测试。地图上的桩标记是贴桩时的车体参考点，不是充电桩外壳或后墙位置。

原桩稳定充电且停稳后，工程按保存锚点初始化定位，再由 AMCL 扫描匹配收敛。明显歪贴不会当作准确落位直接覆盖定位。

## 手动使用面板

1. 贴在已标定原桩：点“车在桩位：初始化”；其它位置用“设置位置”拖出车头方向。
2. 看红色雷达、地图墙线、实车车头一致，再点定位确认。
3. “添加点”点白色通道，拖动设置到达方向。
4. 逐点设置停留时间；可单点前往，也可多点巡航。
5. 需要返回时点“主动回充”；巡航结束回充可提前勾选。

命令行也可操作：

```bash
./kit api status
./kit api initial_dock   # 只在已放回保存的桩位后使用
./kit api confirm
./kit api return
```

## 已有控制策略

- 普通点：先到位置，再处理最终朝向，停稳后开始停留。
- 直线与转弯：RPP 跟踪有效路线，受阻时用原生规划和恢复；保留车身足迹碰撞检查。
- 采集路线：连续 FollowPath，不对每个采样格停车调头；直线与弯道使用不同速度和前视距离。
- 回充：先到桩前，再连续交给厂家 STM32 红外找正、后退和压合；持续充电及轮停后才完成。
- 首次贴合失败：停轮复核后，任务可再执行一次原生回充；迟到的稳定充电反馈会直接收敛到完成，不再顶桩。

## 新车首次验收

按顺序做：0.5 m 直行停车 → 90° 转向 → 两点巡航各停留几秒 → 从走廊返回桩前并回充。检查墙线是否一致、车轮是否空转、最终位置朝向、触点与充电灯。通过后再增加距离和任务数量。

换新地图后重设导航点；重新建图或移动充电桩后重新标桩。原图未变化、仅桌椅移动时，实时雷达与代价地图负责避障。
